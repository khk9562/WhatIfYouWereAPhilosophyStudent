# WhatIfYouWereAPhilosophyStudent

What if you were a philosophy student at a Korean university in the 21st century? Choose some answers and get the result!

## 당신이 21세기 대한민국 대학의 철학과 학생이 된다면?!

실행 명령: npm run start

## 배포
- 단독 주소: https://what-if-you-were-a-philosophy-student.vercel.app
- 게임 포털: [fusion_game_portal](https://github.com/khk9562/fusion_game_portal)의 `/games/philosophy/` 경로로도 열립니다.
- 두 곳에서 모두 동작하도록 자산은 상대 경로(`"homepage": "."`)로 불러오고, 라우터 basename은 현재 주소에서 계산합니다(`src/shared/basename.ts`).
